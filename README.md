# SWYNEX Interactive Dashboard

## Project Overview
An interactive Power BI dashboard created for Task 3 of the SWYNEX Data Analyst Internship.

## Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analysis

## Dashboard Features
- Total records and KPI cards
- Income distribution analysis
- Education vs. income analysis
- Workclass distribution
- Weekly working hours analysis
- Interactive filters for education, workclass, and gender
- Key insights summary

## Key Insights
- 75.91% of individuals earn $50K or less.
- 24.09% earn above $50K.
- Private-sector workers account for 69.68% of the dataset.
- Individuals earning above $50K work more hours on average.
- The cleaned dataset contains 32,537 records.
